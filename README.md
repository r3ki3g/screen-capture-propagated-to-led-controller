# Screen Observer

Your LED lights follow the main colour on a computer screen, like an ambient TV light.

## Use it

1. Open the page in Chrome or Edge on a computer.
2. Paste the access key. Ending it with `---YourName` also picks whose lights.
3. Press **Send this screen** and pick the screen, window or tab.
4. On the phone with the lights, press **Follow my screen**, set to the same person.

Colour tuning shows how the colour is picked, step by step. Its presets are saved per person, so they're the same on every computer.

## Publish

Upload `index.html` to the repository, then go to **Settings → Pages → Deploy from a branch** and pick `main` with `/ (root)`. The page is live at `https://<user>.github.io/<repository>/` a few minutes later. The version under the title shows when an update has gone live.
